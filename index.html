Drive to one ZIP

Paste Google Drive file or folder links. Everything is downloaded, kept in its folder structure, and packed into a single ZIP with no 2 GB splits.

Google requires a free key to read shared folders. It stays on this computer.

  1. Open Google Cloud, create a project, then enable Google Drive API under APIs & Services → Library.
  2. Under APIs & Services → Credentials, choose Create credentials → API key.
  3. Paste the key here.

Public links work without signing in. Sign in only for private files or folders; your Google credentials stay on the server and are never sent to this page.
